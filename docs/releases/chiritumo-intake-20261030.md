# チリツモ経由クーポンURLの受信分離

依頼：ARUNOMATICの受信・仕分けを維持し、チリツモからのURLは同じ仕分け機能を持つ「チリツモ」タブへ表示する。

- タブは受信／仕分け／チリツモ／当選リスト／CP連携。
- items・cards・pending_confirmationsにintake_sourceを追加。既存データはarunomaticのまま残す。
- 同一商品・期限でも初回確認と仕分けカードを受信元ごとに分離する。商品マスターと仕分け後の当選リスト機能は共用する。
- `/api/chiritumo/receive` はチリツモ用のURL送信専用窓口。読取り・管理操作は既存の端末ログインを維持する。受付IDとURLの既存一意制約により二重登録を防ぐ。
- チリツモ側のVercel APIから固定宛先へ転送する。ユーザーによるキー設定は不要。
- 同一URLが従来経路で登録済みの場合は、移動せず重複扱いとする。
- 公開前に影響する4テーブルの暗号化バックアップを保存し、復元照合後に追加カラム・インデックスだけを反映する。既存業務レコードを削除しない。
- 本番検証は識別可能なCHIRITEST URLだけを送信する。実クーポンの利用操作は行わない。
