# TikTok Lite 長時間動画の自動仕分け・一括コピー

利用者の2026-10-28指示に基づき、既存当選URL管理サイトを改修・本番公開する。

- `https://lite.tiktok.com/t/英数字/` の形式を `Tiktoklite長時間動画` に自動分類。URLの英字大小・クエリ・受信日時を保持。形式による利用者指定分類で、実際の動画尺を測定する機能ではない。
- 通常受信・送信専用トークン・キュー・未判定再解析から同じ分類へ。クーポン解析、初回商品確認、CP仕分け、商品単価登録を不要とする。
- 当選リストに専用カードを表示し、カード内の「一括コピー」で受信順のURLだけを改行区切りで取得。あるてぃかーへ貼り付け後に抽出済み確定。中断・再コピー・直前の確定取り消しが可能。コピー中の新着は次回分へ残す。
- 専用2表で抽出状態を保持し、Ledger商品/当選/収益には登録しない。クーポン使用状況の再解析からも除外する。
- サイトに既に保存された対象URLも復旧する。割当済み当選・使用済み・削除済み・明示的な暫定保管中は変更しない。受信モードA〜Eは既存の暫定保管を優先し、勝手に公開しない。
- 全体Exportが完了待ちで停止したため、本番前に対象リンクのitems/unresolvedと参照するcards/product_master/pendingを読み取り退避し、既存schemaで別SQLiteへ全対象行を実復元・完全一致・整合性/FK確認後、既存の復旧用公開証明書で暗号化して共通運用の非公開GitHubの専用backup branchへ保存する。平文のデータ・鍵・トークンは成果物に含めない。
- 0012の2表/2indexだけを追加する。既存schema/runtime/Cron/登録端末認証を保持し、過去のmigrationを一括再適用しない。
- 同一main SHAの全既存CI、追加SQLite試験、スマホ幅のChromiumによるコピー/失敗/中断/確定試験、公開後のWorker・静的配信バイト・認証ガード照合を実施する。
- Android APKは変更対象外。ARUNOMATIC code59内だけに保存されたリンクは、このサイトへ未送信のため自動収集できない。
- 実スマートフォンでの貼り付け・最終確認は未実施。
