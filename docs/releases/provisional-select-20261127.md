# 暫定：自動で閉じる問題の修正と、選択した項目だけのカード化

利用者の2026-11-27の指示に基づき本番公開する。
統括CURRENT Version 2026-11-08.1 を確認。

- 仕分けタブ表示中は8秒ごとの自動更新で暫定パネル全体が再描画され、開いていた「保管内容を確認・削除・カード化」が数秒で閉じ、入力途中のカード化設定も消えていた。再描画の前後で保管箱ごとの開閉状態・入力内容・チェック状態を保持し、自動更新では閉じないようにした（public/provisional-ui.js）。
- 各項目にチェックボックスを追加し、「選択したものだけカード化」でチェックした項目だけを1つのカードへ移せるようにした。選択していない項目は暫定に残り、保管箱は開いたまま維持される。「表示中の全件を選択」も追加した。従来の全件カード化（この暫定をカード化）は変更しない。
- サーバー側（src/provisional.js の publishBucket）は item_ids 指定時のみ部分カード化する。受信中の保管箱では実行しない（409 PROVISIONAL_BUSY）。選択に処理済み・他の保管箱の項目が混じる場合は全体を中止する（409 PROVISIONAL_CHANGED）。形式不正は400。
- 物理DELETE・本番DBスキーマ・認証・収益・中央台帳・通常受信・公開URLは変更しない。migrationは実行しない。
- 一覧表示は従来どおり先頭40件まで。チェックで選択できるのは表示中の分のみで、全件カード化は従来どおり全件が対象。

公開対象は PR #31（マージコミット 9694cd2a9d00b74235e84b66ca42909aac71fa2a）を含む main。公開は専用ワークフロー provisional-select-release.yml で行い、公開前に check と全テストを再実行する。GitHub CI は PR #31 で成功済み。ローカルでは全210件中208件合格（残り2件は PWA アイコンのバイナリ未取得と miniflare 未導入という環境要因で、変更前も同一の2件が失敗することを確認済み）。新規テスト tests/provisional-publish.test.mjs 7件で、部分カード化・残りの全件化・従来動作の不変・409/400・受信中ガード・再描画後の状態保持を検証した。
