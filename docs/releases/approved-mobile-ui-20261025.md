利用者が2026-10-25に「実機確認するので本番まで改修して」と指示。

当選と仕分けの表示名を別々のエイリアスとして保存する。全角14文字相当上限と、保存時の実際の一覧欄・フォント・太さ・余白で検査し、収まらなければ保存しない。文字大や画面幅が変わった後の再検査はその条件で行う。既存の長い正式名を自動短縮せず、一覧では横スクロールで全文を保持する。プレビューは折り返し・省略記号で合格を偽装しない。正式名・識別キー・product_id・抽出状態は変更しない。

ヘッダーの当月／当日2段常設、ドット式タブ、44px相当の下限、レイアウト内のフッター、容量等／引換先1行、右上合計、縦線、未抽出の固定ラベル・3桁数字幅、横並び設定、受信主行、条件付き初回確認入口、CP検索／状態フィルターを統合。4桁以上の未抽出も丸めない。期限の警告・自動優先は標準にしない。CP名は設定と抽出確認内、常時表示は利用者の選択。再解析は設定から確認後に開始する。

単価はJSON number型の非負の安全な整数だけ受理する。null・空文字・空白・false・配列・数値文字列は拒否する。明示的な数値0は0円。確定済みの月収益を再計算しない既存処理は維持。

本番基準はPR #13の6b76bfdを含むa74bb94b-1308-4b88-aa66-88df4818fe4d。高速化を戻さない。公開前に本番版を照合。既存CIを通し、公開Workflowはlegacy npm run deployを使わない。新規ui_display_namesテーブルだけ追加し、既存テーブル／行／認証／Secrets／変数／Cron／Queueを保持する。0010は再実行可能なCREATE IF NOT EXISTSだけで、全migrationを再実行しない。

## 商品設定の追加（未抽出閲覧・終了済みへの手動移動）

利用者の追加依頼による本番改修。未抽出の内容を50件ずつ読み取り専用で表示する。方式未設定・現在の方式では対象外のデータも含み、対応件数と全件数を分ける。コピー・URLを開く操作では抽出状態を変更しない。抽出確定や一括処理の既存手順を維持する。

終了済みへの移動は商品単位の一覧整理として実装し、CP全体の終了確定とは分ける。専用ui_product_settingsに手動移動状態を永続化し、通常一覧へ戻せる。CP終了済みの商品は従来どおり終了領域に置き、CPの訂正手続きを飛ばして通常へ戻さない。未抽出、単価、収益、正式名、ID、割当、同期を変更しない。表示名保存用の既存テーブルも維持する。

公開基準はversion 5cd6ded0-44ab-4b51-8776-f49e679ca279。DB更新は0011の新規テーブルCREATE IF NOT EXISTSだけ。既存データの移動・抽出確定・キャンペーン終了は公開時に実行しない。実機確認は反映後。
