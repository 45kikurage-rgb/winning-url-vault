# 抽出済みを含む全件再コピー — 2026-11-03

利用者承認：当選管理システムの各商品カードで「抽出済みを含む全件再コピー」を追加し、本番まで反映する。チャージスポット・ピクトリンクなど、保存済みの当選コードに共通適用する。

## 変更内容
- 各商品カードに「全件再コピー」を表示。未抽出が0でも使用できる。
- 登録順（受信日時→IDの昇順）と逆順（降順）を選択し、200件ごとの認証付き読取をすべて収集。取得件数が表示中の商品件数と一致しない場合はコピーしない。
- 取得後、ユーザーの明示的なタップでクリップボードへコピーする。コピーが拒否された場合は選択可能なテキストで手動コピーできる。
- 既存「1件ずつ抽出」「未抽出を一括コピー」「昇順で一括コピー」は維持。
- APIはGETのみ。抽出済み日時・分類・商品集計・収益・URL本文・履歴・D1構造・Secret・他アプリには変更を加えない。
- 「逆順」は当選管理側の登録順の逆であり、AIRWalletの実チャージ成功順を意味しない。既に使用済みの判定はしない。
